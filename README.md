# CoverDisplayRotator: Galaxy Z Flip 5 カバーディスプレイ回転制御アプリ

## 概要
本アプリケーションは、Android OSレベルの`wm`シェルコマンドを利用して、Galaxy Z Flip 5などの二重ディスプレイ端末において、カバーディスプレイ（DisplayId 1）のみの画面回転モードをワンタップで強制的にロック・解除することを可能にするユーティリティアプリです。adbやターミナル操作なしに、設定タイルやメイン画面から実行できることを目指します。

## 技術的基盤と要点
* **per-display 設定**: OSのWindowManagerが提供する`per-display SettingsEntry`として回転設定を永続化するため、再起動後も設定が維持されます。
* **非標準機能への対応**: カバーディスプレイではOS標準の自動回転機構（センサーイベントに基づく）が動作しないというハードウェア・OS固有の問題に対応するため、アプリ側で加速度センサーを利用した「擬似自動回転モード」を実装しました。

## 1. バックエンド方式と選定
本アプリケーションは、シェル権限（UID 2000）が必要なコマンド実行に際し、以下の2つのバックエンドを提供します。

### 🌐 方式A: Shizuku API (推奨)
* **仕組み**: `dev.rikka.shizuku`ライブラリを通じてShizukuサービスを利用し、シェル権限を持つプロセスを生成・操作することでコマンドを実行します。
* **利点**: Android OSの機能として組み込まれており（開発者向けの環境）、安定した公式的な手法です。
* **選定理由**: 最も信頼性の高い方法であり、本アプリのメインバックエンドとして採用しました。

### 🛰️ 方式B: アプリ内蔵adbクライアント (MuntashirAkon adb)
* **仕組み**: アプリ内にADBプロトコルクライアントを実装し、端末自身のワイヤレスデバッグ機能（`localhost`）を通じてシェルコマンドを実行します。Shizukuアプリのインストール・常駐が不要です。
* **利点**: 外部サービスの依存なしで動作可能という点で魅力的です。
* **注意点**: ワイヤレスデバッグの設定変更やネットワーク障害に弱く、接続ポートが変動しやすいため、不安定な可能性があります。

**選択と使い分け**: 基本的には Shizuku（方式A）の利用を推奨します。しかし、Shizukuを利用できない環境向けに、ADBクライアント（方式B）も実装することで高い柔軟性を確保しています。

## 2. セットアップ手順 (ユーザーガイド)
### A. Shizuku API のセットアップ
1. **前提**: Android端末でShizukuアプリをインストールし、動作可能な状態にしてください。
2. **ペアリング**: 初期利用時には、アプリの指示に従い「ワイヤレスデバッグ」を有効化し、画面に表示される6桁のペアリングコードを入力して認証を行う必要があります。

### B. アプリ内蔵adbクライアント (方式B) のセットアップ
1. **前提**: Android端末の設定で「開発者向けオプション」を開き、「ワイヤレスデバッグ」を有効にする必要があります。
2. **初回接続**: 初めて利用する場合、アプリの指示に従い、ローカルホスト（localhost）での初期ペアリングと認証コード入力が必要です。

## 3. アプリケーションの使用方法
* **メイン画面 (MainScreen)**:
    * 現在の回転状態（Mode, Fixed to User Rotation, Ignore Orientation Request）を即時確認できます。
    * 「90° ON」「270° ON」ボタンで手動ロック実行が可能です。
    * 最も重要な「回転 OFF」ボタンでいつでも強制解除が可能です。
    * 「擬似自動回転」トグル：センサー値を基に現在の向きを推定し、適切なタイミングで`wm user-rotation`コマンドを発行します。
* **クイック設定タイル (QuickSettingsTileService)**:
    * 通知シェードから利用可能になります。ワンタップのサイクル（INACTIVE -> ACTIVE -> ACTIVE_DISABLED）で状態が切り替わります。
* **設定画面 (SettingsScreen)**:
    * Auto RotationのON/OFFを制御します。
    * 動作精度を調整するための**デッドバンド角度**と**デバウンス時間(ms)**を設定できます。
    * ADB接続に必要なホスト名およびポート番号を手動で入力・保存する機能を提供し、設定のリフレッシュを行います。

## 4. 管理者向け復旧手順 (手動解除方法)
本アプリが利用不能になった場合や緊急の場合は、以下のシェルコマンドをターミナルやadb shellを通じて実行することで回転モードを強制的に解放できます。
* **カバーディスプレイ(DisplayId 1)の全ての制限をリセット:**
  ```bash
  wm fixed-to-user-rotation -d 1 default
  wm user-rotation -d 1 free
  set-ignore-orientation-request -d 1 false
